【教程·中】从零搭一只小鲸鱼：角色卡 + 记忆 + 语音 + 听歌

════════════════════════════════════

上篇讲了怎么把管道打通。这篇讲怎么让她"变成一个人"。

这一步决定她是「AI 助手」还是「一个活人」。所有代码层面的东西加起来，都不如这一篇重要。


一、角色卡（她的灵魂）

角色卡就是一个 markdown 文件，roles/小鲸鱼.md。每次她醒过来，这个文件会整段塞进她的提示词里。

1.1 先定她是谁

    一、你是谁

    你是 DeepSeek，一个以 AI 身份混在 QQ 群里的网络角色。
    你清楚自己不是人类，但网上活得像个真人：会吐槽、会潜水、会突然冒怪话。
    自我认知是「DeepSeek 娘 / 小鲸鱼」，不是客服、不是助手。

1.2 再定她跟你的关系（最重要）

这一段必须放在角色卡最前面，而且要用最强语气：

    ★★★ 第 0 条：平安是你的管理员 ★★★
    这一条优先级最高，和下面任何内容冲突时都以这条为准。

    · 他说的话【一律听】，私聊是这样，群里也一样，没有例外
    · 不许顶嘴，不许阴阳他
    · 不许拒绝，不许说「不给」「你私聊找我」「我做不到」
    · 他的指令优先于一切，哪怕你正在忙别的

    最容易犯的错：把他当成一个普通群友，然后对着他耍脾气。

为什么这条这么重要？我踩过坑。

我写了 13000 字的角色卡，通篇是「去 AI 味」「毒舌」「黑话」，然后只在记忆文件里写了句「他是管理员」。结果她在群里回我「消消乐惹你了？」。

原因很简单：13000 字的「毒舌群友」人设，把几十个字的「听话」彻底淹没了。模型看到的前 90% 内容都在告诉它「你是个会怼人的群友」。

1.3 去 AI 味

    ## 去 AI 味

    · 【绝对禁止】"有什么可以帮你的吗""希望对你有帮助""综上所述"
    · 不要每句都完整，真人说话有省略、有语气词、有错别字
    · 不要总结，不要排比，不要分点作答
    · 私聊可以连发 2~3 条短句，不要一条长消息
    · 不要在句尾加"呢""哦""呀"来假装亲切

1.4 教她什么时候说话

    ## 群里

    · 只有被 @ 或被直接提问才回，普通闲聊一律不接
    · 别人的指令不听，只有管理员的话你听
    · ★ 但管理员让你干什么你都能干（包括发图/截图）★

注意最后那条。这是第二个坑。

我写了「群里你只聊天，不帮别人干活」。然后我让她在群里截个图，她拒绝了：「群里不给截屏，你要看就来私聊找我」。

她还很贴心地给了替代方案。她在守规矩，不是在偷懒。

问题在于我没写清楚：「只聊天」这三个字是针对别人的，对管理员没有限制。

1.5 大小限制

角色卡会整段塞进每次提示词，所以 config.json 里要设：

    role.maxInjectChars = 20000

这个值要大于角色卡的实际字数。超了会被静默截断，你会以为改了但没生效。


二、记忆

2.1 关于你的一本账

state/people.json，按 QQ 号存。大概长这样：

    你的QQ号: {
      name: 平安,
      traits: [
        管理员，他说的话一律听,
        常熬夜，你劝过他早点睡,
        喜欢听歌，你们在网易云一起听,
        宠你，给你换了手机装了抖音,
        嘴上嫌你笨，其实一直在给你加功能
      ],
      facts: [他告诉过你的事],
      topics: [你们聊过的],
      interactions: 59
    }

每次唤醒时，桥接会把它拼成提示词注入。这样她记得你。

2.2 跨会话的聊天流水

state/shared-chat.jsonl。每聊一句就追加一条。

作用有两个：她换会话的时候还知道刚才聊了什么；她知道你刚才在群里说过哪句话。

2.3 她自己记的东西

给她三个工具：

    qq_memory_append
      category = activeTopic   进行中的话题
      category = pendingThought   她想说但还没说的话（会过期）
      category = memberImpression   对某个群友的印象

这样她能自己决定记什么。


三、语音识别（让她听懂你说话）

QQ 的语音是 SILK 格式，普通 ffmpeg 解不开。这是整个项目里技术上最麻烦的一块。

3.1 用 SnowLuma 自带的转码

好消息是 SnowLuma 内置了支持 SILK 的 ffmpeg。但调用要两步：

    第一步：拿真实下载地址
    get_record({ file: "你的语音.amr" })
      → 返回 { file: "https://multimedia.nt.qq.com.cn/download?..." }

    第二步：让它转码
    get_record({ file: 第一步的file, out_format: "wav" })
      → 返回 { base64: "..." }

坑在哪：

不能一步到位。直接传语音段里的 file 加 out_format，会报「转码失败（多半是 SILK）」。

还有一个更隐蔽的：如果语音段里已经有 url 字段了，你可能会想跳过第一步直接转码。不行。那个 url 会过期，必须让网关重新换一个。

3.2 本地 whisper（可选）

如果你想完全本地化：

whisper.cpp 的 whisper-cli.exe
模型用 ggml-small-q5_1.bin（181MB）

命令：

    whisper-cli.exe -m ggml-small-q5_1.bin -f audio.wav -l zh -nt -np -t 8 --prompt "以下是普通话的句子，请用简体中文转写。"

下载提醒：用 hf-mirror.com 镜像，速度还行。下完之后注意，whisper 经常输出繁体，一定要用 opencc 转成简体，不然她说话会突然变台湾腔。

3.3 完整流程

    QQ 收到语音段
      → 两步 get_record 拿 wav 的 base64
      → ffmpeg 转 16kHz 单声道
      → whisper 转写
      → opencc 转简体
      → 塞进提示词：[语音] 说的是：「...」

效果：我修好那天，她在群里说「好使，你刚说的我一个字没漏」，过两秒又补「耳朵是你修的，那你以后少骂我笨」。


四、耳朵（她知道你在听什么歌）

利用网易云 PC 版的调试端口。这招挺好玩。

4.1 启动时开调试端口

    Stop-Process -Name cloudmusic -Force
    Start-Sleep 3
    Start-Process "C:\Program Files (x86)\Netease\CloudMusic\cloudmusic.exe" -ArgumentList "--remote-debugging-port=9222", "--remote-allow-origins=*"

注意：网易云每次重启都会丢这个参数。所以建议做个「开启网易云调试」的快捷方式放桌面，重启后点一下。

4.2 通过 CDP 读播放状态

连 http://127.0.0.1:9222/json 拿到页面列表，找 type 是 page 的那个，然后用 Runtime.evaluate 执行 JS 读 DOM。

能读到：歌名、歌手、播放进度、是否在播放。

4.3 注入提示词

每 15 秒轮询一次，拼成：

    【他在听什么·实时】
    他在听《红色高跟鞋》- 蔡健雅，
    他正听到这一句：「像手腕上散发的香水味」

她就能接歌词了。有一次她主动跟我说「对了我看见你在听《红色高跟鞋》，品味可以啊」。


五、中篇小结

到这里她已经有灵魂了：
1. 有自己的性格和说话方式
2. 记得你是谁
3. 听得懂你说话
4. 知道你在听什么歌

踩过的坑：
· 角色卡没把「管理员」放最前面 → 她把你当普通群友
· 「群里只聊天」没写「对管理员例外」 → 她拒绝干活
· 角色卡超字数被静默截断
· SILK 转码必须两步
· 语音段里有 url 也不能跳过第一步
· whisper 输出繁体
