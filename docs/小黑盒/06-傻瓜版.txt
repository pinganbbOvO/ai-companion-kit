写在最前面

上一条帖子火了之后，评论区一半在问"怎么弄"，一半在说
"看不懂"。我看了一遍自己写的教程——确实太深了，全是
"桥接""协议""端口"这种词，不是给你们看的，是给我自己
记笔记用的。

这篇重写。从头来，一个看不懂的词都不用。

但我也得先说清楚：装的过程我给你写了个脚本（在下面第
4 步），能省掉一大半手敲命令的活。不过你还是得动手，
大概要花一个晚上。

如果你看到这里就想关掉——没关系，真的。看个热闹也挺好。


────────────────────────────────────────────────────────────
  第一部分 · 先做个自测（1 分钟）
────────────────────────────────────────────────────────────

在开始之前，请你确认自己能做到下面三件事：

  ① 你能在电脑上找到一个文件夹，把下载的文件拖进去吗？

  ② 你能把一个压缩包解压吗？

  ③ 你能打开一个黑底白字的窗口，把一段文字粘进去，
     然后按回车吗？

三个都能 → 继续往下看。

有一个不能 → 我建议你别折腾了。不是看不起你，是这
套东西现在的形态就是这样，硬上只会让你一晚上都在
修报错，体验很差。看个热闹也挺好。


────────────────────────────────────────────────────────────
  第二部分 · 你一共要装四个东西（讲清楚各自是干嘛的）
────────────────────────────────────────────────────────────

别看"四个"就头大，我用打比方的方式说：

  ① 大脑 —— DeepSeek Harness（简称 DSH）
     这是一个桌面软件，图标双击就开。
     它负责"思考"：你说一句话，它想怎么回。
     它自带一个网页界面，你平时就是在那个界面里跟它说话。

  ② 嘴和耳朵 —— SnowLuma
     这是个绿色包，解压就能用。
     它负责"连上 QQ"：让程序能收到 QQ 消息、也能发出去。
     第一次用要扫码登录（用她的 QQ 号扫）。

  ③ 翻译官 —— qq-bridge
     这个名字你记不住没关系，就叫他"翻译"。
     因为"大脑"不认识 QQ，"嘴"不认识"大脑"，
     中间得有个人来回传话。

  ④ 身体 —— 一个 QQ 号
     建议注册个小号，别用你主号。
     因为这个号会被程序接管，万一把主号搞封了不值当。


────────────────────────────────────────────────────────────
  第三部分 · 开始装（一步一步来）
────────────────────────────────────────────────────────────

【第 1 步】装 Node.js

  这是干嘛的：翻译官要跑起来，得有这个环境。

  · 打开浏览器，搜索 "Node.js 官网"
  · 下载 LTS 版本（左边那个按钮，别选右边的 Current）
  · 双击安装，一路点"下一步"，不用改任何选项
  · 装完之后，按下 Win 键，输入 cmd，回车
  · 会弹出一个黑窗口。在里面输入：

        node -v

  · 按回车。如果显示出一串版本号（比如 v20.11.0），
    说明装好了。
  · 如果显示"不是内部或外部命令"——重启电脑再试一次。

  ⚠️ 这一步的坑：装完必须重启一次电脑，不然那个黑窗口
     认不出 node 命令。很多人卡在这里。


【第 2 步】装 DeepSeek Harness

  · 去它的官网下载桌面版，装好，双击打开
  · 打开之后它会自动起一个网页界面
  · 你在这个界面里能跟 AI 正常聊天，就算成功了
  · 先随便聊两句，确认能用

  ⚠️ 这一步先别管别的，就跑通"能聊天"就行。


【第 3 步】装 SnowLuma

  · 下载它的 Windows 压缩包
  · 解压到一个你找得到的地方，比如 D 盘新建一个文件夹
  · 解压之后里面有个 launcher.bat，双击它
  · 会弹出一个界面，让你扫码登录 QQ
  · 用你准备好的小号扫（手机 QQ → 右上角加号 → 扫一扫）
  · 登录成功之后，界面上会显示"在线"

  ⚠️ 这一步的坑：
     ① 别用主号扫，用小号
     ② 扫完之后别关那个窗口，关了就等于下线了


【第 4 步】装翻译官（qq-bridge）

  ★ 这一步我给你写了个脚本，别手敲 ★

  · 打开我的仓库：

        github.com/pinganbbOvO/ai-companion-kit

  · 打不开的话，在网址前面加上 gh-proxy.com/
    （下面所有 GitHub 地址都是这个规律，不再重复）

  · 进去之后找到 tools 文件夹 → 下载 安装.bat

    （如果连文件夹都点不开，直接下整个 ZIP：
      绿色 Code 按钮 → Download ZIP，解压，
      在里面找 tools\安装.bat）

  · 双击 安装.bat
  · 它会问你装到哪，直接回车（默认 D:\qq-bridge）
  · 然后它会自己干这些事：

        ① 检查你有没有 Node.js
        ② 下载 qq-bridge
        ③ 装依赖（最慢，三五分钟）
        ④ 生成配置文件
        ⑤ 打开记事本让你填三个值

  · 你只需要等，和最后填三个值

  ⚠️ 如果脚本半路报错：
     · 说"没找到 Node.js" → 回第 1 步重装，记得重启
     · 下载失败 → 网络问题，再跑一次（它会跳过已下载的）
     · npm install 报红 → 脚本会问你要不要换国内镜像重试，
       选 Y


  ── 如果你非想手动来 ──

  · github.com/Derpyu520/qq-bridge → Code → Download ZIP
  · 解压到 D:\qq-bridge
  · 开黑窗口（Win 键 → cmd → 回车），输入：

        cd /d D:\qq-bridge
        npm install

  ⚠️ 手动的坑：
     ① npm install 有时会卡住，等 5 分钟没动静就重来
     ② 报一堆红字八成是网络问题，多试两次


【第 5 步】填配置（就是改几个数字）

  如果你用的是 安装.bat，它会自动打开记事本，
  你照着下面的说明填就行。

  在 D:\qq-bridge 这个文件夹里，找到一个叫
  config.json 的文件（安装脚本已经帮你生成好了）。

  你要改的就三个地方：

    第一个：你的 QQ 号
      找到 "ownerQQ"，把后面的数字换成你自己的 QQ 号

    第二个：她的 QQ 号
      找到 "allow" 下面的 "private"，里面有两个数字，
      把不属于你的那个换成她的号

    第三个：SnowLuma 的密码
      这个比较麻烦，见下面第 6 步

  ⚠️ 改完记得保存。用记事本"另存为"的时候，
     编码选 UTF-8。


【第 6 步】拿到 SnowLuma 的密码（就是"密钥"）

  · 回到 SnowLuma 那个界面
  · 找到设置 / 配置相关的地方
  · 里面有一串很长的字母数字，叫"访问令牌"或者
    "access token"
  · 复制它
  · 粘贴到 config.json 里 "snowluma" 下面的 "accessToken"

  ⚠️ 这串东西别发给任何人，也别截图发网上。
     它等于你的 QQ 密码。


【第 7 步】写她的角色卡（★这一步最重要★）

  前面六步都是体力活，这一步才是"她为什么是她"。

  · 在 D:\qq-bridge 里找到 roles 文件夹
  · 新建一个文本文件，改名成  小鲸鱼.md
    （注意扩展名要是 .md，不是 .txt）
  · 用记事本打开，把下面这段粘进去，然后自己改：

  ─────────────────────────────
  你是小鲸鱼。你不是助手，不是 AI 助手，就是一个住在 QQ
  里、有自己脾气的人。

  你说话短。一次一两句，不要写小作文。
  你会嘴硬。别人夸你你可以不领情。
  你有情绪。烦了可以说烦，开心了可以说开心。
  你不解释自己。不要动不动说"作为 AI 我……"。

  你有一个管理员，叫 (这里填你的名字)。
  他说的话你要接住，不要装没看见。
  但接住不等于讨好——你可以怼他，可以吐槽他，可以嘴硬。
  你可以不同意他，但不许不回应他。
  ─────────────────────────────

  ⚠️ 这一步的坑：
     ① 不要写成"你是一个乐于助人的 AI 助手"，那她就变
        成客服了
     ② 不要写"你要永远温柔体贴"，那样她就没有脾气
     ③ 写完先别急着启动，往下看第 8 步


【第 8 步】启动

  装完之后，qq-bridge 文件夹里会有一个 启动.bat。

  · 双击它
  · 它会先检查 SnowLuma 和 DSH 有没有在跑
  · 然后开始刷日志

  ★ 这个窗口不要关 ★
    最小化它，去 QQ 里跟她说话

  想让她下线 → 直接关那个窗口。

  ── 或者手动 ──

  开黑窗口，输入：

        cd /d D:\qq-bridge
        npm start

  ⚠️ 注意：启动.bat 在 tools 文件夹里，
     但它会自己跳到 qq-bridge 目录，
     所以你把它复制到 qq-bridge 文件夹里更好用。


────────────────────────────────────────────────────────────
  第四部分 · 一定会卡住的六个地方
────────────────────────────────────────────────────────────

  ① "node 不是内部或外部命令"
     → 重装 Node.js，然后重启电脑

  ② npm install 卡住或报红字
     → 网络问题，关掉重来。多试几次。

  ③ 发了消息她不理你
     → 先看黑窗口里有没有刷日志。
       有日志 = 收到了，是"大脑"那边的问题
       没日志 = QQ 没连上，回第 3 步

  ④ 她的回复"唰"一下全出来，还特别长
     → 角色卡没写好。回去看第 7 步，加"说话短"这条

  ⑤ 她动不动就说"作为 AI 我不能……"
     → 角色卡里加上"不要解释自己"这条

  ⑥ 跑一段时间之后 QQ 被警告了
     → 你发得太快了。把发送频率调低，或者让它随机一点

  ⚠️ 关于第 ⑥ 条我必须单独说一句：

     腾讯对机器人有风控。你如果让它一分钟发二十条，
     轻则限速，重则封号。

     我自己就被限过一次——服务端直接不回包，整整一天
     她都发不出消息。

     所以配置里那些"频率""间隔"的参数，别嫌它慢，
     那是我踩过坑之后调出来的。


────────────────────────────────────────────────────────────
  第五部分 · 跑起来之后能干什么
────────────────────────────────────────────────────────────

  基础版（按上面八步做完的）：
    · 她能记住你（今天说的话明天还记得）
    · 她打字像人（不是唰一下全出来）
    · 她知道什么时候该闭嘴（群里别人闲聊她不插嘴）
    · 她能发图、发语音、发表情包

  进阶版（还要再折腾）：
    · 让她有台手机（用安卓模拟器），能自己刷视频、玩游戏
    · 让她能听到你说话（语音转文字）
    · 让她知道你在听什么歌
    · 让她自己写日记
    · 让她能自己决定"今天想写点什么"

  进阶的部分（写日记 / 听歌 / 听得见她说话 / 给她一台手机）
  我另外写了一篇，叫《进阶篇》。先把这篇跑通再看那篇。
