## 你需要准备

- 一台 **Windows** 电脑（常开）
- 一个 **QQ 小号**（别用主号）
- 一个 **DeepSeek API key**
- **30 分钟**（其中 15 分钟在等下载）

## 第 2 步：让 QQ 能被程序控制（5 分钟）

```powershell
cd E:\SnowLuma

```

1. 出二维码 → 用**小号的手机 QQ** 扫码
2. 浏览器开 `http://127.0.0.1:5099`
3. 开启 **HTTP 服务**（端口 `3000`）和 **WS 服务**（端口 `3001`）
4. 设一个 **Access Token**，记下来

**验证一下**：

```powershell
$T = "你刚设的token"
Invoke-WebRequest 'http://127.0.0.1:3000/get_status' -Method POST `
  -Body ([System.Text.Encoding]::UTF8.GetBytes('{}')) `
  -ContentType 'application/json' `
  -Headers @{ Authorization = "Bearer $T" } -UseBasicParsing
```

看到 `"online":true` 就成了 ✅

## 🚨 三条保命规则

### ① 频率千万别调高

```jsonc
"socialV2": {
  "send": {
    "maxSendPerMinute": 6,      // ❌ 不要 20
    "maxSendPerHour": 80        // ❌ 不要 300
  }
}
```

**真实教训**：我调成 20/300，某天发送通道卡了 23 分钟，
桥接每 15 秒重试一次，一天下来**失败 14 次 vs 成功 18 次**。
腾讯直接开始不回包：

```
packet OidbSvcTrpcTcp.0xfd4_1 failed: gotResponse=false
failed to load friends for UIN xxxxxxxxx
```

这就是**风控**。（不是封号，但继续作死会升级）

### ② 一定要加熔断器

连续失败 3 次 → **停 3 分钟**，期间不去重试。

```javascript
const circuit = {
  consecutiveFails: 0, openUntil: 0,
  allow() { return Date.now() < this.openUntil
    ? { ok: false, reason: '熔断中' } : { ok: true }; },
  fail() {
    if (++this.consecutiveFails >= 3)
      this.openUntil = Date.now() + 180000;
  },
  ok() { this.consecutiveFails = 0; }
};

// 发送前
if (!circuit.allow().ok) return;   // ★直接跳过
```

### ③ "正在输入"别发太勤

我一天发了 **175 次** `set_input_status`。真人不会这样。

```jsonc
"typing": {
  "minCharsForTyping": 20,   // 短消息不发
  "minIntervalMs": 45000,    // 最少隔 45 秒
  "probability": 0.35        // 35% 概率
}
```

```powershell
  try { $c = New-Object Net.Sockets.TcpClient; $c.Connect('127.0.0.1',$p); "OK $p"; $c.Close() }
  catch { "XX $p" }

Get-Content 'E:\qq-bridge\state\bridge.log' -Tail 30

# ③ 看熔断器
Invoke-WebRequest 'http://127.0.0.1:3100/api/socialV2/breaker' `
  -Headers @{'X-Console-Token'='控制台token'} -UseBasicParsing
```

**中文变成 `????`？** PowerShell 的锅：

```powershell
-Body ([System.Text.Encoding]::UTF8.GetBytes($body))
-ContentType 'application/json; charset=utf-8'
```

**改了代码不生效？** MCP 进程是常驻的，要杀掉才会重载：

```powershell
Get-CimInstance Win32_Process -Filter "Name='node.exe'" |
  Where-Object { $_.CommandLine -match 'mcp-snowluma' } |
  ForEach-Object { Stop-Process -Id $_.ProcessId -Force }
```
